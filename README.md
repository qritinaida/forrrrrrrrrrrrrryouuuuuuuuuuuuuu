# 💖 For You - เว็บเซอร์ไพรส์คู่รักสุดน่ารัก (Couple Surprise Web App)

เว็บเซอร์ไพรส์แฟน/คนรัก ดีไซน์น่ารัก โทนสีพาสเทลมินิมอล อบอุ่น พร้อมลูกเล่น Interactive แบบ Step-by-Step ออกแบบมาให้เป็น Static Web (HTML5 + CSS3 + Vanilla JavaScript) **พร้อมอัปโหลดขึ้น GitHub และเปิดใช้งาน GitHub Pages ได้ฟรีทันที 100%!**

## ✨ ลูกเล่นและฟีเจอร์เด่น (Features)

1. 💌 **ซองจดหมายปริศนา (3D Wax Seal Envelope)**:
   - ตราประทับขี้ผึ้งสีแดงหรูหรา แตะเปิดซองจดหมาย 3D พร้อมเริ่มเล่นเสียงเพลงและจุดพลุหัวใจ
2. 👩‍❤️‍👨 **นาฬิกานับเวลาความรัก Realtime (Love Counter)**:
   - นับวัน ชั่วโมง นาที วินาที ตั้งแต่วันแรกที่คบกันหรือวันที่พบกัน
3. 😜 **คำถามวัดใจปุ่มวิ่งหนี (Playful Love Question)**:
   - ถามว่า "รักเค้ามั้ย?" ปุ่ม "ไม่รัก" จะแกล้งขยับหนีเมาส์/นิ้วแตะ พร้อมข้อความหยอกล้อ ส่วนปุ่ม "รักสิ" จะยิ่งขยายใหญ่ขึ้นเรื่อยๆ
4. 📸 **แกลเลอรีความทรงจำสไตล์โพลารอยด์ (Polaroid Album)**:
   - กรอบรูปแปะเทปวาชิสุดคิ้วท์ พร้อมคำบรรยายและวันที่ กดดูรูปใหญ่ (Lightbox) ได้
5. 📝 **จดหมายความในใจ (Typewriter Love Letter)**:
   - พิมพ์ข้อความซึ้งๆ ทีละตัวอักษร พร้อมปุ่มกดส่งหัวใจรัวๆ
6. 🎵 **เพลงและเสียงกล่องดนตรี (Romantic Audio)**:
   - รองรับไฟล์ `.mp3` ของตัวเอง และมีระบบเสียงกล่องดนตรี (Music Box Synth) เล่นให้อัตโนมัติแม้ไม่มีไฟล์เพลง
7. 🌸 **ละอองหัวใจและประกายวิ้งลอยบนหน้าจอ (Canvas Hearts Particles)**:
   - ลื่นไหล 60 FPS สวยงามทั้งบนคอมและมือถือ

## 🛠️ วิธีการปรับแต่งข้อมูล (Easy 1-File Customization)

คุณสามารถแก้ไขข้อมูลทั้งหมดได้ง่ายๆ ในไฟล์ **`config.js`** เพียงไฟล์เดียว:

```javascript
const CONFIG = {
  // 1. ชื่อของคุณและแฟน
  couple: {
    yourName: "เตง (เค้าเอง)",
    partnerName: "คนดีของเค้า",
    nickname: "เจ้าความสดใส ✨",
  },

  // 2. วันที่เริ่มคบกัน (รูปแบบ: ปี-เดือน-วันTชั่วโมง:นาที:วินาที)
  startDate: "2024-01-01T00:00:00",

  // 3. เพลงพื้นหลัง (ใส่ไฟล์ mp3 ใน assets/music/ หรือใส่ URL เพลงได้เลย)
  music: {
    src: "assets/music/romantic.mp3",
    volume: 0.6,
  },

  // 4. รูปภาพความทรงจำ (นำรูปมาวางในโฟลเดอร์ assets/images/)
  memories: [
    {
      image: "assets/images/photo1.jpg",
      caption: "เดทแรกของเรา จำได้มั้ยตื่นเต้นสุดๆ เลย",
      date: "14 กุมภาพันธ์ 2024"
    },
    // เพิ่มรูปตามต้องการ...
  ],

  // 5. ข้อความจดหมายความในใจ
  loveLetter: {
    title: "ถึงคนเก่งของเค้า...",
    paragraphs: [
      "ขอบคุณที่เข้ามาเป็นรอยยิ้มให้เค้าในทุกๆ วันนะ...",
      "รักเธอที่สุดในโลกเลยนะ 💖"
    ],
    closing: "รักเสมอและตลอดไป,",
    signOff: "จากแฟนคนนี้เอง 🥰"
  }
};
```

## 🚀 วิธีนำขึ้น GitHub และเปิด GitHub Pages ใน 3 ขั้นตอน

### ขั้นตอนที่ 1: อัปโหลดโค้ดขึ้น GitHub Repository
1. เข้าไปที่ [GitHub.com](https://github.com) แล้วกด **New repository**
2. ตั้งชื่อ เช่น `foryou` หรือ `my-love` (ตั้งเป็น **Public**) แล้วกด **Create repository**
3. อัปโหลดไฟล์ทั้งหมดในโปรเจกต์นี้ขึ้นไป หรือใช้คำสั่ง Git:
```bash
git init
git add .
git commit -m "feat: romantic surprise website for you"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

### ขั้นตอนที่ 2: เปิดใช้งาน GitHub Pages
1. ในหน้า Repository บน GitHub ให้ไปที่แถบ **Settings** (การตั้งค่า)
2. เมนูด้านซ้าย เลือก **Pages**
3. ในหัวข้อ **Build and deployment** > **Branch**:
   - เปลี่ยนจาก `None` เป็น `main` (หรือ `master`)
   - โฟลเดอร์เลือกเป็น `/ (root)`
4. กด **Save**

### ขั้นตอนที่ 3: รับลิงก์ส่งให้แฟน! 🎉
- รอประมาณ 1-2 นาที GitHub จะสร้างลิงก์เว็บไซต์ให้คุณ เช่น:
  `https://your-username.github.io/foryou/`
- สามารถคัดลอกลิงก์ส่งเซอร์ไพรส์แฟนใน LINE, Facebook Messenger, หรือทำเป็น QR Code บนการ์ดของขวัญได้เลย!

## 📂 โครงสร้างโฟลเดอร์ (Directory Structure)

```text
foryou/
├── index.html            # โครงสร้างหน้าเว็บหลัก
├── style.css             # สไตล์และการตกแต่งธีมสีพาสเทล
├── config.js             # 🌟 ไฟล์ตั้งค่าหลัก (ชื่อ วันที่ รูปภาพ ข้อความ)
├── app.js                # ระบบ Interactive, นับเวลา, พลุ, ตัวหนังสือพิมพ์
├── README.md             # คู่มือแนะนำการใช้งาน
└── assets/
    ├── images/           # โฟลเดอร์เก็บรูปภาพความทรงจำ
    │   ├── photo1.svg
    │   ├── photo2.svg
    │   ├── photo3.svg
    │   └── photo4.svg
    └── music/            # โฟลเดอร์สำหรับใส่เพลง .mp3
        └── README.txt
```

## 💡 คำแนะนำเพิ่มเติม
- **การเปลี่ยนรูป**: นำไฟล์รูปของคุณ เช่น `photo1.jpg`, `photo2.png` มาใส่ในโฟลเดอร์ `assets/images/` แล้วเปลี่ยนชื่อไฟล์ใน `config.js` ได้เลย
- **เปิดดูในคอมทันที**: ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดดูผ่านเบราว์เซอร์ (Chrome, Safari, Edge) ได้ทันทีโดยไม่ต้องรันเซิร์ฟเวอร์
- **เสียงเพลง**: ตามนโยบายของเบราว์เซอร์ เพลงจะเริ่มเล่นหลังจากแตะเปิดซองจดหมาย (ซึ่งนับเป็นการโต้ตอบของผู้ใช้) อย่างนุ่มนวล
